# Password Generator

A simple Password Generator web application built using HTML, CSS, and JavaScript.

## Features

- Generate random passwords
- Select password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Password strength: Weak, Medium, Strong
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
